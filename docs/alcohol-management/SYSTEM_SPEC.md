# אפיון מערכת ניהול אלכוהול — Invistimo

עודכן: 2026-10-25 (Asia/Jerusalem)

## מצב קיים (מה פותח בפועל)

### מכירה ושירות
- תוספת מכירה `alcoholManagement` במערכת העובדים (`app/employee/sales/new/page.tsx`).
- כוללת אנשי צוות (1 או 2 לפי היקף/רשומות) ותיעוד ממוחשב כחלק מהשירות.
- **לא** כוללת רכישת אלכוהול או אספקת בקבוקים.

### מודל נתונים
- `models/EventAlcohol.ts`: `eventId`, `category`, `brand`, `flavor`, `total`, `allocations[]` עם `location`, `qty`, `opened`.
- API:
  - `GET/POST /api/events/[eventId]/alcohol`
  - `PATCH/DELETE /api/events/alcohol/[id]`

### ממשק תפעולי
- `AlcoholManagementTab.jsx` באזור production של האירוע.
- מצבים: תכנון מלאי, הקצאות, ניהול לייב (פתיחת בקבוקים).
- לוג פעולות מקומי ב־`localStorage` + ייצוא TXT של הלוג.
- יש דמו עם נתוני המחשה.

### מחשבון תכנון (לפני האירוע)
- `/info/guides/wedding-alcohol-calculator` — תכנון כמויות ועלויות, נפרד משירות יום־האירוע.

## מה עדיין בתכנון / לא להציג כמוצר פעיל מלא

| יכולת | סטטוס |
|---|---|
| ייצוא PDF / Excel של דוח סיום מלא | לא ממומש (קיים ייצוא TXT ללוג) |
| סטטוס נפרד «ריק» מעבר ל־opened | לא ממודל במפורש |
| QR / מזהה ייחודי לכל בקבוק פיזי | לא קיים (ברקוד יצרן ≠ יחידה) |
| הרשאות מלאות לפי תפקיד (צוות אלכוהול / בעל אירוע / מנהל־על) עם בידוד אירועים | חלקי בלבד דרך מערכת האירועים הקיימת |
| Audit log שרת־צד עמיד | לוג מקומי בצד הלקוח כיום |
| התראות מלאי נמוך | לא ממומש |
| Offline / התאוששות רשת מלאה | לא מאומת כמוצר |

## הצעת ארכיטקטורה להמשך (ענף נפרד)

1. **ישויות**: EventAlcoholProduct, Location, InventoryLot / BottleUnit (אופציונלי), StockMovement, StaffAssignment, ClosingReport.
2. **סטטוסים**: סגור במחסן · סגור במיקום · פתוח · ריק שדווח · הוחזר · פער מלאי.
3. **תנועות בלתי הפיכות לוגית**: קליטה, הקצאה, העברה, פתיחה, סימון ריק, החזרה, התאמת ספירה, סגירת אירוע — עם `actorId`, timestamps, source/target.
4. **אילוצים**: אין מלאי שלילי; אין פתיחה מעל סגור זמין; מניעת כפל לחיצה; עדכונים מקבילים עם version/etag.
5. **ממשק צוות**: מסך מובייל/טאבלט עם פעולות מהירות בלבד.
6. **רמת מעקב**: ברירת מחדל = כמות לדגם; אופציה עתידית = יחידה עם QR פנימי.

## עמוד שיווקי

- נתיב: `/services/alcohol-management`
- טופס הצעת מחיר: `POST /api/services/alcohol-quote` → אותו יעד תמיכה כמו טופס יצירת קשר (`SUPPORT_EMAIL` / Resend).
- **אין מחיר קבוע בעמוד** — הצעת מחיר מותאמת בלבד.

## מדיניות פרסום

- מותר לתאר: אנשי צוות + תיעוד מלאי/הקצאה/פתיחה + סיכום לפי מה שתועד.
- אסור להבטיח: מניעת גניבות, חיסכון מובטח, זיהוי אוטומטי של שתייה, PDF/Excel לפני פיתוח.
