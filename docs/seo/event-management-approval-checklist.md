# רשימת אישורים לפני פרסום

**אין לבצע Merge או Deploy ללא אישור מפורש.**

## יכולות ושירותים שאומתו בקוד/מוצר

| פריט | סטטוס |
|---|---|
| מערכת ניהול: משימות, ספקים, תקציב, לו״ז, לוגיסטיקה | מאומת בדמו `/try/event-management` |
| אלכוהול ומתנות במודולי ניהול | קיימים בדמו המוצר |
| אישורי הגעה / הושבה / LIVE | שירותים נפרדים / תוספות — מוצג כך בעמוד |
| טופס פנייה → `/api/contact` | מאומת (Resend); שדות נוספים נארזים ב־message |
| Header/Footer ציבוריים | ללא שינוי ניווט אחרי login |
| URL מדריך חדש | `/info/guides/event-management-vs-production` |
| URL שירות | `/event-management` ללא שינוי |

## דורש אישור לפני פרסום

1. **היקף שיתופי פעולה עם מנהלי אירועים** — כיסוי גאוגרפי אמיתי, אופן הזמנה ותנאי שירות.
2. **ניסוח «עובדת עם מנהלי אירועים ברחבי הארץ»** — לוודא התאמה לפעילות בפועל.
3. **תכולת ליווי מקצועי** — מה נכלל במסלול הפעיל בפועל.
4. **תכולת מנהל ביום האירוע** — שעות, צוות, ספקים, הושבה, רזרבות.
5. **צילומי מסך ייעודיים** למשימות/תקציב/תשלומים/לו״ז (כיום חלקם המחשות או מסכי מוצר קרובים).
6. **תמונות אנשי מקצוע** — אין לפרסם שמות/תמונות בלי אישור.
7. **טווחי מחיר שוק** — לא פורסמו; אם רוצים טווחים — מקורות ישראליים עדכניים + תאריך.
8. **OG image ייעודי** למדריך (כיום ברירת מחדל של האתר).
9. **בדיקת שליחת טופס בסביבת staging/production** עם מפתחות Resend פעילים.
10. **אישור משפטי/עסקי** לטענות שירות לפני עלייה לפרודקשן.
