## כללי תוכן לפרופילים

1. אין להמציא מספרי לקוחות, דירוגים או «מקום ראשון בגוגל».  
2. קישור ראשי לאתר הפרודקשן אחרי Deploy — לא ל־Preview tunnel.  
3. עדיף קישור ל־hub המתאים (`/rsvp`, `/pricing`) אם יש שדה אחד בלבד — לבחור `/` או `/rsvp` לפי מדיניות המדריך.  
4. אחרי URL פרופיל יציב — אפשר (באישור) לשקול הוספה ל־`sameAs` בסכמה.
