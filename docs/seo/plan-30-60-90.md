# 30 / 60 / 90 days after publish

Assumes the SEO branch is merged and deployed with owner approval. No ranking guarantees.

## Days 1–30 — Foundation

1. Deploy marketing SEO changes; confirm `robots.txt`, `sitemap.xml`, `llms.txt`, `answers.json` on production.
2. Verify site in Google Search Console and Bing Webmaster; submit sitemap.
3. Set `NEXT_PUBLIC_GA_MEASUREMENT_ID`, Google and Bing verification env vars.
4. Run Rich Results Test on `/`, `/rsvp`, `/rsvp/chatuna`, `/pricing`, one guide, `/faq`.
5. Capture baseline: GSC impressions/clicks (if history exists), GA4 sessions on content groups, CWV from Search Console if available.
6. First AI monitor pass (six fixed questions) → spreadsheet.
7. Fix any FAIL from owner acceptance / Rich Results without inventing schema.

## Days 31–60 — Measurement & content polish

1. Review GSC queries; fill Keyword Map volumes only from real exports.
2. Strengthen underperforming primary URLs with answer clarity and internal links (no new thin pages).
3. Expand FAQ only with real support questions.
4. If Google Business / social profiles are approved, add verified `sameAs`.
5. If demo videos get posters + publish dates, add VideoObject on those pages only.
6. Second AI monitor pass; compare citations.
7. Off-page: start approved directory / venue mention outreach list (no spam).

## Days 61–90 — Authority & conversion

1. Compare 28-day Search + conversion cohorts vs days 1–30.
2. Prioritize pages with impressions but low CTR (title/description tests — keep factual).
3. Publish at most 1–2 new guides only when a distinct query with real demand appears in GSC.
4. Venue/producer co-marketing and genuine review requests (approved channels only).
5. Re-run `npm run test:seo` in CI on every marketing change.
6. Third AI monitor pass; document engines that cite Invistimo URLs.
7. Decide whether IndexNow / Bing extras are worth enabling (approval if paid).
