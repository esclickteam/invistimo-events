# מנוע חישוב — מחשבון אלכוהול לחתונה

עודכן: 2026-10-25 (Asia/Jerusalem)

נתיב: `/info/guides/wedding-alcohol-calculator`

## עקרונות

- כמויות לתכנון **רכישה** בלבד — לא המלצת צריכה.
- אין טענה ל«ניסיון כמויות» של Invistimo ואין מחירי שוק מומצאים.
- חישוב אלכוהול רק לפי אורחים בגיל שתייה חוקי שסומנו כצפויים לשתות.
- אין ייחוס שתייה לקטינים.
- משך האירוע **אינו** מגדיל אוטומטית כמויות.
- מוצג טווח (נמוך–גבוה) עם אפשרות עריכה ידנית.
- מותג משפיע על אריזה/מחיר שהמשתמש מזין — לא על נוסחת הביקוש עצמה.

## בסיס האורחים

1. `expectedGuests` — אורחים צפויים בפועל.
2. `legalAgeGuests` — מוגבל ל־`expectedGuests`.
3. `expectedDrinkers` — מוגבל ל־`legalAgeGuests`.
4. `youngLegalAgeGuests` — הקשר להרכב קהל בלבד; לא משנה כמויות.

## הנחות ברירת מחדל (ניתנות לעריכה)

| פרמטר | ברירת מחדל |
| --- | --- |
| מנות לשותה (נמוך–גבוה) | לפי אופי אירוע: רגוע 2–3 · מגוון 2.5–4 · מסיבה 3–5 |
| מ״ל חריף | 40 |
| מ״ל יין | 150 |
| מ״ל בירה | 330 |
| חלק קוקטיילים (כשיש גם חריפים) | 15% מהביקוש האלכוהולי |
| שתייה קלה לאורח | 2–4 מנות תכנון |
| מים | ~0.75 ל׳ לאורח |

## חלוקת ביקוש (מניעת ספירה כפולה)

1. סך מנות אלכוהול = `drinkers × servingsPerDrinker` (טווח).
2. אם נבחרו קוקטיילים **וגם** משקאות אחרים — חלק הקוקטיילים נגרע ראשון.
3. היתרה מחולקת **לפי קטגוריה** (לא לפי מספר בקבוקים באותה קטגוריה), ואז בתוך הקטגוריה בין הבקבוקים שנבחרו.
4. המרה ליחידות: `ceil((servings × pourMl) / packageMl)`.
5. `toPurchase = max(0, planned − venueIncluded)`.
6. משקאות ללא אלכוהול מחושבים בנפרד לפי כל האורחים הצפויים; אם האולם מספק שתייה קלה — כמות הרכישה ל־NA אופסת (עד עריכה ידנית).

## השוואת עלויות

**רכישה עצמאית:** בקבוקים + דמי מזיגה (לפי בקבוק / אורח / קבוע) + הובלה + קירור + קרח + ברמנים + מיקסרים + ציוד − החזר צפוי על סגורים (לא מובטח).

**חבילת אולם:** מחיר חבילה + לפי אורח + שדרוגים + קוקטיילים + ברמנים + שירותים חסרים + מסים.

אין הכרזה על חלופה זולה יותר כשאחד הצדדים חסר נתונים. החזר סגורים מוצג תמיד עם הסתייגות בכתב.

## הבדלים מדוגמת המתחרה

- עיצוב Invistimo (שמנת/זהב) — לא שחור/כבד.
- קטלוג בקבוקים ויזואלי עם תמונות מוצר מורשות מקומית.
- השוואת עלות כוללת (דמי מזיגה, שירותים) ולא רק רשימת בקבוקים.
- הנחות שקופות לעריכה + טווחים.
- דגש על החזרת סגורים וצ׳קליסט מול האולם.
- חיבור לאישורי הגעה של Invistimo.
