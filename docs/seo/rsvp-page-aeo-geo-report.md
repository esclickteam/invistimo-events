## AEO / GEO
התוכן עונה ישירות על:
- מה השירות עושה
- למי מתאים
- מסע האורח
- מעקב מצד המארגן
- ערוצי תקשורת (WhatsApp / SMS / שיחות)
- עיתוי מומלץ (כהמלצה, לא כחובה)
- חיבור להזמנות ולהושבה
- הבדלים בין מסלולים

הוסר מבלוק `/rsvp` הכותרת «התשובה הקצרה» (AnswerFirst), כדי לא לייצר תוכן שנראה כמו תשובה מלאכותית למודלים. התשובות נשארות גלויות במקטעי העמוד וב־FAQ.
