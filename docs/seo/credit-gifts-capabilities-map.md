## 1. סליקת אשראי (RSVP)

| פריט | ממצא |
| --- | --- |
| ספק | RSVP (חיצוני) — לא סליקה של Invistimo |
| הרשמה | `https://ktzr.io/giftInvistimoSignup` (מובייל / מסמכי מכירה) |
| אישור משתמש | עד 2 ימי עסקים אחרי השלמת פרטים |
| עמלה | 2.5% מהמתנה — על האורח |
| זיכוי | עד 5 ימי עסקים; «העברת זהב» 100 ₪ עד יום עסקים אחד |
| מחיר תוספת Invistimo | 150 ₪ (קל להזמין) / 100 ₪ (מזמינים חכם) / כלול במזמינים ומושיבים |
| שמירה במערכת | `event.gifts.creditEnabled` + `creditUrl` (+ `giftCreditUrl` לתאימות) |
| תצוגת אורח | `GiftSection`, עמוד `/e/[shareId]`, אתר חתונה |
| הודעות | תבניות WhatsApp/SMS עם קישור מתנה באשראי |

**דורש אישור:** שינוי תהליך סליקה או הבטחות זיכוי מעבר למסמכי RSVP/מכירה.
