# אפיון מערכת ניהול מלאי אלכוהול — Invistimo

**סטטוס:** אפיון + מיפוי תשתית קיימת. **אין Deploy** עד אישור קבלה.

## 1. מה קיים היום

| רכיב | מיקום | מצב |
|------|--------|-----|
| מודל מלאי בסיסי | `models/EventAlcohol.ts` | קטגוריה/מותג/טעם/`total` + `allocations[{location, qty, opened}]` |
| API | `app/api/events/[eventId]/alcohol`, `app/api/events/alcohol/[id]` | CRUD בסיסי |
| UI תפעולי | `AlcoholManagementTab.jsx` ב־`/events/production` | מצבי planning / allocation / live |
| מכירה/אפסל | `salesUpsells.alcoholManagement` ב־User / EmployeeSale | מחיר צוות (1→1200 / 2→2000) במכירות פנימיות |
| מחשבון תכנון | `/info/guides/wedding-alcohol-calculator` | חיצוני, לא תלוי במלאי |
| עמוד שירות ציבורי | `/services/alcohol-management` | Preview — שיווק + לידים |

## 2. פערים מול הדרישה

- אין יומן תנועות (`InventoryMovement`) עם audit מלא.
- אין הפרדה סטטוסית מלאה: סגור במחסן / סגור במיקום / פתוח / ריק / הוחזר / פער.
- אין תפקידים ייעודיים (AlcoholStaff) מעבר להרשאות אירוע כלליות.
- אין מניעת מלאי שלילי ברמת טרנזקציה / concurrency.
- אין ייצוא PDF/Excel מאומת.
- אין QR לבקבוק בודד (מעקב כמותי לפי דגם בלבד).
- מחיר שיווקי קבוע אסור בעמוד הציבורי; מחירון תפעולי פנימי קיים חלקית במכירות.

## 3. מודל מוצע (הרחבה על הקיים)

### ישויות

1. **EventAlcoholProduct** — קטגוריה, מותג, דגם, נפח, יחידה, תמונה, SKU/ברקוד אופציונלי.
2. **AlcoholLocation** — bar / table / storage / reserve / custom, שייך ל־`eventId`.
3. **AlcoholStockLedger** — יתרות לפי `(eventId, productId, locationId, sealState)` כאשר `sealState ∈ {sealed, open, empty, returned}`.
4. **AlcoholMovement** — קליטה / הקצאה / העברה / פתיחה / ריק / החזרה / התאמת ספירה / סגירת אירוע; שדות: זמן, actorUserId, product, qty, from/to location, notes, correlationId לתיקונים.
5. **AlcoholServiceAssignment** — שיוך אנשי צוות לאירוע + תפקיד.

### רמת מעקב

**שלב א׳ (מומלץ):** מעקב כמותי לפי דגם+נפח+מיקום+מצב חותם.  
**שלב ב׳ (אופציונלי):** מזהה ייחודי לבקבוק (QR פנימי). ברקוד יצרן מזהה סוג מוצר בלבד.

## 4. תפקידים

| תפקיד | גישה |
|--------|------|
| SuperAdmin | כל האירועים, דוחות, הגדרות |
| EventManager | אירוע משויך: מלאי, צוות, דוחות |
| AlcoholStaff | אירוע משובץ בלבד + פעולות מותרות |
| EventOwner | תמונת מצב ודוח לפי הרשאות השירות |

איש צוות לא רואה מלאי של אירועים אחרים.

## 5. ממשק צוות (מובייל/טאבלט)

מסך ראשי: שם אירוע, סגורים / פתוחים / ריקים / רזרבה, התראות סף, פעולות אחרונות.  
פעולות מהירות: פתח · העבר · הקצה · סמן ריק · החזר סגור · ספירה.

## 6. כללי תקינות

- אין מלאי שלילי; בדיקה אטומית בטרנזקציה.
- אין פתיחה מעל כמות סגורה במיקום.
- אישור לפני תיקונים משמעותיים; תיקון = תנועת reverse + תנועה חדשה (לא מחיקת היסטוריה).
- מניעת כפל לחיצה (`idempotencyKey`).
- עדכונים מקבילים: version / optimistic lock על יתרה.
- הצגת `lastUpdatedAt` בממשק.
